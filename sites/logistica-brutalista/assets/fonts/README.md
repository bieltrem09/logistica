# Fontes auto-hospedadas (opcional)

Hoje as fontes vêm do Google Fonts (`display=swap` + `preconnect` no `<head>`).
Para hospedar aqui: baixe Anton, Inter Tight (400/500/600) e JetBrains Mono (400/500) em WOFF2,
coloque os arquivos nesta pasta, declare os `@font-face` no topo de `css/style.css`
e remova o `<link>` do Google Fonts em `index.html`.
